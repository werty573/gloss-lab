# Gloss Lab: concept website

A single-page site for **Gloss Lab**, a fictional mobile car detailing and ceramic coating in Central Trinidad.

Concept build by **Portside Digital**: websites that work. Gloss Lab is not a real business.

**Look:** Unbounded + Geist, dark garage palette with one acid-lime accent.

**Scroll animation** (GSAP + ScrollTrigger, switched off for people who prefer reduced motion):
- Hero lights up, then pushes in as you scroll
- Scroll-driven before/after wipe
- Process line that draws itself
- Stacking package cards
- Live quote builder (vehicle, package, add-ons)

Forms validate and show a success state, but don't send anywhere. On a client build they'd go to the owner's WhatsApp.

Photos: [Unsplash](https://unsplash.com) (Unsplash License).

Open `index.html` in a browser. There's no build step.
